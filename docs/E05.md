# E05: paired quality, latency and cost smoke comparison

Two configurations answer the same three authored development questions. Each
generated answer is evaluated by the same custom gpt-5.4-mini JSON rubric and E04
structural gate. The reference is never scored. Model order alternates per query.

```powershell
python -m pip install -r requirements-offline.lock
python -m pytest -p offline_guard tests -q
# Optional paid run: CPython 3.11, OPENAI_API_KEY supplied securely
python compare_smoke.py --output artifacts/E05-live.json
```

This permits six generation calls (three per model) and six judge calls, each
limited to 1,024 completion tokens with no automatic retry and a USD 0.25 per-run
allowance. Use a new output directory for another paid run; an existing usage
ledger cannot be overwritten. This is not an account-level/shared-team spend cap.

Reports include generated outputs, case identities, fixture hash, source revision,
prompt, policy, resolved model IDs and dated USD pricing assumptions. Generation
and judging costs are separate. Failed attempts remain in failure/latency counts;
missing usage is explicit rather than proven free. Retry count/cost is zero.

P50/P95 use linear interpolation over sorted observations. At n=3, p95 is merely
descriptive, not a stable tail estimate or SLO. The judge can prefer its own model
family; no independent expert assessment, repeats or statistical superiority is
established. These scores are custom rubric outputs, not comparable RAGAS scores.

Among configurations passing this fixture, the report identifies lower measured
generation cost. That is a provisional decision on a small example, not a
production-model recommendation. B01 remains deferred; this is not a benchmark.

This branch is stacked on E04 and must follow its review/merge. Generated results
are ignored and exported in the handoff package. See evidence/E05.md for the run.
